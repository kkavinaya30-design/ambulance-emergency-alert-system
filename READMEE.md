# Ambulance Emergency Alert System

## Overview
A Java-based simulation designed to notify registered vehicles when an ambulance is approaching their upcoming road, helping vehicles move aside to support emergency movement.

## Features
- Models ambulances, registered vehicles, and roads.
- Represents a road network connecting Gandhipuram, Ganapathy, Peelamedu, and Singanallur.
- Uses a five-minute alert threshold in the simulation.
- Sends alerts to relevant vehicles on the upcoming road.
- Demonstrates object-oriented programming concepts in Java.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Visual Studio Code

## How to Run
1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open a terminal in the folder containing the Java source files.
4. Compile the Java files:

   `javac *.java`

5. Run the main program:

   `java Main`
